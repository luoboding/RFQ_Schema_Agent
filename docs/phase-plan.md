# RFQ Schema Agent 阶段任务与完成情况

**基准日期**：2026-10-19  
**范围**：仅覆盖本仓库的 RFQ Schema Agent，以及与其直接相关的邮件接入、审核和评估。Supplier Extraction Agent、RFQ Action Agent 的实现不计入本项目完成度。

状态说明：**已完成**＝代码与离线测试具备；**部分完成**＝已有实现，但仍缺少 PRD 所需能力或真实环境验证；**未开始**＝尚无对应实现；**待决策**＝PRD 留有产品选择。

## 建议的下一批任务

1. **P0：真实环境联调**。用专用测试邮箱和测试密钥跑通 `watch-imap → 表单落库 → 本地审核页`；记录失败场景与端到端耗时。
2. **P0：匿名标注集**。确定字段标注规范，收集不同语言、模糊表述、附件场景的 RFQ，运行评估并复核漏判。
3. **P1：附件可见性**。v1 至少在表单和审核页提示附件名称及“内容未解析”，防止采购员误以为附件已纳入推导。
4. **P1：线程与下游契约**。确定邮箱线程映射，与 Extraction／Action Agent 验证字段定义、修订版本和待确认状态的消费规则。
5. **P1：审核页验收**。用真实浏览器验证操作时间、历史查看需求和本机访问边界。
